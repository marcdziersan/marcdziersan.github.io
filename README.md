## Positionierung

- Junior Anwendungsentwickler im Berufseinstieg

## Gestaltungsprinzip

- ruhige Informationsarchitektur nach dem Muster professioneller Engineering-Portfolios
- kurze, belastbare Aussagen statt Marketing-Floskeln
- Projekte werden über Problem, Entscheidung, Umsetzung und Ergebnis erklärt
- kein Skill-Rating, keine Prozentbalken, keine animierten Effekte
- Systemfonts, keine externen Fonts oder UI-Bibliotheken
- responsive für Desktop, Tablet und Smartphone

## Technik

- keine Cookies

- keine externen Abhängigkeiten
